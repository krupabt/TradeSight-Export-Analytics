# TradeSight Export Analytics – Power BI Integration

This directory contains the complementary Power BI business intelligence reporting suite for **TradeSight Export Analytics**, developed for the Cynaris Solutions client project and university evaluation.

## Contents
- **`TradeSight_Analytics.pbip`**: Open directly in Power BI Desktop.
- **`TradeSight_Analytics.Dataset/`**: Tabular Object Model (`model.bim`) with 5 tables and 30+ DAX measures.
- **`TradeSight_Analytics.Report/`**: Visual layout (`report.json`) defining the 5 interactive pages.
- **`data/`**: Star-schema modeled CSV datasets.
- **`power_query/`**: M transformation scripts for ETL replication.
- **`dax/`**: Complete DAX measures library and documentation dictionary.
- **`theme/`**: TradeSight Navy & Light corporate JSON theme.
- **`POWERBI_SETUP_GUIDE.md`**: Step-by-step instructions to validate and save `TradeSight_Analytics.pbix`.

For detailed setup and validation, please refer to [POWERBI_SETUP_GUIDE.md](POWERBI_SETUP_GUIDE.md).
